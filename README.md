## 🚀 How to Use This Repository

1. **Clone the whole thing**  
   `git clone https://github.com/Mayankk0608/DevOps-Worklab.git`

2. **Navigate to any project** and follow its `README.md`.  
   Every tool is isolated enough that you can study just one piece.

3. **Run Ansible playbooks** against your own VMs by adjusting the Tailscale IPs and usernames.

4. **Break things on purpose** – this repo is designed for learning by failure and self‑healing.
