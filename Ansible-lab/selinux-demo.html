🔒 SELinux Contexts

Rocky Linux 9 · Nginx · User : Role : Type : Level
📌 CONTEXT FORMAT
system_u object_r httpd_sys_content_t s0
👤 SELinux User 🎭 Role 🏷️ Type (Enforcement) 📊 Level (MLS/MCS)

🔍 Check File Context

ls -lZ /webroot/html/index.html

⬆️ The -Z flag shows SELinux context.
Without proper httpd_sys_content_t → 403 Forbidden

⚙️ Process Context

ps axZ | grep nginx

Nginx runs as system_u:system_r:httpd_t:s0
It can only read files with type httpd_sys_content_t

$ sudo semanage fcontext -a -t httpd_sys_content_t "/webroot/html(/.*)?"
$ sudo restorecon -Rv /webroot/html
✅ This page is served from /webroot/html/
SELinux context correctly set → access granted
👤 Regular User
echo "Hello" > /webroot/html/test.txt
# Allowed only if DAC + SELinux permit
👑 Root (sudo -i)
sudo -i
# Root bypasses DAC,
# but SELinux STILL enforces!
